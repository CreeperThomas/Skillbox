# Skillbox Implementation Plan

> **For agentic workers:** Use executing-plans / inline execution. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Skillbox.app, a native SwiftUI macOS skill manager for `~/.agents/skills`, buildable with Command Line Tools only.

**Architecture:** One SwiftPM package with a pure-logic library `SkillboxCore` (scanning, parsing, classification, toggling, GitHub/skills.sh clients, installer, AI client) and a SwiftUI executable `Skillbox` (three-column NavigationSplitView). A shell script wraps the release binary into a `.app` bundle.

**Tech Stack:** Swift 6.3 (CLT), SwiftUI, WebKit (WKWebView for Markdown preview), Foundation URLSession, CryptoKit, Security (Keychain). No third-party packages.

**Spec:** `docs/superpowers/specs/2026-10-08-skillbox-design.md`

## Global Constraints

- No Xcode; `swift build`, `swift test`, `swiftc` only. Module cache must be set to a workspace-local path (`-module-cache-path` / `SWIFTPM` default inside `.build`).
- Zero third-party Swift dependencies.
- Deployment target macOS 26.0.
- Skills root `~/.agents/skills`; disabled root `~/.agents/skills-disabled`.
- SKILL.md is the source of truth; catalog.json stores only derived/user data.
- Swift language mode 5 for the package (avoid strict-concurrency churn in UI code); Core types `Sendable` where cheap.
